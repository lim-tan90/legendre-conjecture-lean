# Layer 5 — short-interval prime theorems

`Statements.lean` contains the normalized exponent specifications and their
interval/gap bridges. Import `Legendre.Layer5` through the stable public entry
point. Add future analytic proofs as separate modules in this directory and
export completed modules from that entry point. Do not mark a paper proved
merely because its statement or literature comparator compiles.

Update both READMEs, the proof map and the literature comparator catalog when
adding a milestone. Keep sources, pinned commits and licenses for adapted code.
